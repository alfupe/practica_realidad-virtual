Descripción:
Aplicación interactiva de experimentación rítmica y secuenciación espacial en compás de 4/4 
construida con HTML5, CSS3 (metodología BEM), JavaScript modular, A-Frame (WebXR) y Web Audio API (<15 ms).
Estructura de dos niveles:
1. Nivel Explorativo: Estudio de producción sintético low-poly con controlador interactivo.
2. Nivel Manipulativo y Contributivo: Secuenciador matricial 4x4 con micro-compresión geométrica Z (100 ms),
   autómata finito de 3 estados (INACTIVO, ACTIVO_ESPERA, DISPARANDO) y doble interfaz física (ratón + teclado isomórfico).
