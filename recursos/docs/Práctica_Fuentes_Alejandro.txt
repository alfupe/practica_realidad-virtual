Descripción:
Aplicación interactiva de experimentación rítmica y secuenciación espacial en compás de 4/4 
construida con HTML5, CSS3 (metodología BEM), JavaScript modular, A-Frame (WebXR) y Web Audio API (<15 ms).
Estructura de dos niveles:
1. Nivel Explorativo (Escena 1): Showroom interactivo y estudio de producción musical con controlador Maschine MK3,
   dos monitores de vídeo diegéticos en 3D que abren demostraciones oficiales vía modal HTML5 <dialog> y atril 3D de recursos.
2. Nivel Manipulativo y Contributivo (Escena 2): Secuenciador matricial 4x4 multi-compás (hasta 4 compases) con pantalla LCD digital,
   navegación por cursores (flechas izquierda/derecha para edición cíclica, arriba/abajo para bucle continuo),
   Modo Libre (*Live Perform*, tecla M o botón físico PAD MODE) para solear en directo sin alterar el patrón programado,
   micro-compresión geométrica Z (100 ms), autómata de 3 estados y teclado isomórfico sin scroll indeseado.
